## Create project and run server

```bash
mkdir tailwind-css-v4-for-beginners-full-course-2026
cd tailwind-css-v4-for-beginners-full-course-2026
npm create vite@latest .
```

```bash
Select a framework: Vanila
Select a variant: TypeScript
Use Vite 8 beta (Experimental)?: No
Install with npm and start now? No
```

```bash
npm install tailwindcss @tailwindcss/vite
```

Create `vite.config.ts` in root:

```ts
import { defineConfig } from "vite";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig({
    plugins: [tailwindcss()],
});
```

Start server:

```bash
npm run dev
```

In `src/style.css` delete all code and paste:

```css
@import "tailwindcss";
```
